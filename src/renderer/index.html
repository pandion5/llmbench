설정

양자화를 바꾸면 3.8 모델을 새로 받는다. 이전 양자화 파일은 models\qwen38 아래 폴더로 남으니 필요 없으면 직접 지운다. 앞에서부터 이 층 수만큼 전문가를 CPU RAM에 둔다. Qwen3.8은 48층이라 48 이상이면 전부 CPU. 47, 46처럼 낮추면 뒷층 전문가가 VRAM으로 올라가는데 한 층에 1~1.4GB라 3080 10GB에선 1~2층이 한계다. 층당 이득은 2% 안팎이다. VRAM이 넘치면 서버가 뜨지 않는다. 바꾼 뒤 설치를 다시 실행해야 반영된다. 스레드가 일감을 기다릴 때 바쁘게 도는 비율. 기본 50. 벤치마크 탭의 튜닝 모드가 좋은 값을 찾아 준다. llama-server --cpu-mask. 하이브리드 CPU에서 P코어만 쓰게 할 때 넣는다. 튜닝 모드 결과를 적용하면 자동으로 채워진다. 3.8의 내장 MTP 헤드로 초안을 뽑아 생성을 빠르게 한다. 켜면 llama.cpp를 unsloth 빌드로 바꿔 받고(약 340MB) MTP 파일(2.6GB)을 추가로 받는다. VRAM을 2.6GB 더 쓴다. 효과는 체감 벤치로 잰다(llama-bench는 드래프트 미지원). 서버 시작 시 Qwen3.6도 같이 올린다. RAM이 두 모델 합계(Q4 기준 125GB)보다 작으면 끈다. 바꾼 뒤 설치를 다시 실행해야 models.ini에 반영된다.
주의 항목이 있다. 그래도 설치할까?
